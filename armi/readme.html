ARMI

The Advanced Reactor Modeling Interface (ARMI®) is an open-source tool that streamlines your nuclear reactor design/analysis needs by providing a software reactor model and a rich ecosystem of tools to interogate that model. It is made by and for professional reactor analysis teams and is maintained by TerraPower LLC, a nuclear technology development company.

ARMI provides:

  • standardized communication between physics kernels

  • a flexible reactor data model

  • dependable input and output data formats

  • an ecosystem for multi-disciplinary simulation and analysis of a nuclear reactor

Demos of ARMI can be seen in the ARMI example gallery.

Using ARMI, plus a collection of ARMI-aware physics plugins, and engineering team can perform a full analysis of a reactor with various input parameters. On larger compute clusters, thousands of perturbed cases are frequently run in parallel. Such studies are useful for both design decisions and senstivity analyses.

ARMI aims to enhance the quality and rigor of computational nuclear reactor design and analysis. Additional high-level information about this system can be found in [1].

Overview

High-Level Architecture

Figure 1 below is meant to represent the high-level goal of ARMI. At the center of the diagram is the ARMI Reactor Data Model, this is a central place in memory where the physical state of the reactor can be viewed and changed. The outer ring of the figure shows “external physics kernels”, which have been written for different nuclear engineering disciplines around the world for decades now. The glue that connects these external software packages to ARMI are “ARMI Plugins” which you write, based on ARMI examples, to read and write data from the ARMI reactor data model. A collection of these plugins can be collected into an ARMI “Application” which orchestrates simulating or analyzing your reactor.

Please note that ARMI does not come with a full selection of physics kernels. You will need to be acquire or develope these yourself for your specific needs. ARMI is just the framework for your modeling. Also, the examples shown in Figure 1 were chosen arbitrarily; ARMI is not limited to these physics kernels, nor should it limit you in what physics you want to model.

Getting Started

Quick Start

Before starting, you need to install Python <https://www.python.org/downloads/>.

Get the ARMI code, install the dependencies, and fire up the launcher with the following commands. You probably want to do this in a virtual environment as described in the Installation documentation.

First, upgrade your version of pip:

$ pip install -U pip>=22.1

Now clone and install ARMI:

$ git clone https://github.com/terrapower/armi
$ cd armi
$ pip install -e .
$ armi --help

The ARMI tests are meant to be run using pytest locally:

$ pip install -e ".[test]"
$ pytest -n 4 armi

From here, we recommend going through a few of our gallery examples and tutorials to start touring the features and capabilities, and then move on to the User Manual.

System Requirements

Being largely written in the Python programming language, the ARMI system works on most platforms. It can perform meaningful analysis on a single laptop, but the full value of design optimization and large problems is realized with parallel runs over large clusters (using MPI via mpi4py).

Misc

Getting Help

You can get help with ARMI by either making issues on our github page or by e-mailing armi-devs@terrapower.com.

Disclaimers

Due to TerraPower goals and priorities, many ARMI modules were developed with the sodium-cooled fast reactors as a target, and are not yet optimized for other plants. This is a known issue and we are working on it. On the other hand, the framework is sufficiently general that teams have modeled other reactor types with ARMI, including thermal reactors.

ARMI is being developed and used within a rapidly-changing R&D environment. It has evolved a great deal, and naturally carries some legacy. We are constantly on the look out for technical debt, and pay it off regularly. If you find some, please make a ticket. Users should understand that ARMI is not a polished consumer product, but a flexible engineering tool.
